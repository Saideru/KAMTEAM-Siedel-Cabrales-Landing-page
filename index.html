01 — Profile

        
I build the web and keep the machines behind it running.

        
I'm Siedel Jeremy Cabrales — a freelance web developer with deep roots in IT support. I design and code full-stack websites for small businesses, then stay on the other side of the screen too: administering databases, diagnosing hardware, monitoring networks and installing IP CCTV. The code, the data and the machines it runs on.
